# FirehallMeals

Purpose:
Free firefighter meal generator and future firefighter performance platform.

Audience:
Firefighters and first responders.

Current Stack:
- React
- Vite
- Express.js
- OpenAI API
- Spoonacular API

Current Problems:
- slow recipe generation
-mixed up recipes
- timeout issues
- weak mobile UX
- repeated meals
- weak onboarding

Architecture Notes:
- Spoonacular handles structured recipe and nutrition data
- OpenAI handles intelligent meal generation and personalization
- Goal is to reduce unnecessary AI calls and improve generation speed

Future Features:
- Firehall Workouts
- subscriptions
- saved cookbook
- mobile app

Brand Direction:
- gritty firefighter culture
- simple
- fast
- premium but not corporate
