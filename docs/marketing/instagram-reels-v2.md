# Firehall Meals V2 — Viral Instagram Reel Concepts

**Use this doc for:** editors, UGC creators, station shoots, and screen-record sessions.  
**Product truth (May 2026):** Classics Wheel lives on `/wheel` (not mixed into Find a Meal). Breakfast is separate at `/breakfast`. Parent brand: [Lights & Sirens Co.](https://www.lightsandsirensco.com).

---

## Style

- Gritty, fast pacing, realistic firefighter energy
- Not polished influencer content
- Fast cuts + loud hooks
- Feels like “inside firehall culture”
- Native to firefighter Instagram / TikTok

## General editing rules

| Rule | Spec |
|------|------|
| Length | 10–15 seconds max |
| Subtitles | Always on |
| Hook | Aggressive in first **1 second** |
| Cuts | Quick jump cuts |
| Sound | Radio chatter, kitchen sounds, turnout gear, station ambience |
| End card | Every reel ends with both lines below |

**Mandatory end card (2 lines, ~2s hold):**

```
FirehallMeals.com
Built by Lights & Sirens Co.
```

**Secondary tagline (use on 3–4 reels, not all):**

```
Firefighter Built. Firehall Tested.
```

## Visual vibe

- Black / red / white
- Cinematic but **real** — not glossy food-blog
- Kitchen-table culture
- Firefighters scrolling between calls
- Rugged and practical

## Screen-record map (app)

| Shot need | URL / flow |
|-----------|------------|
| Find a Meal (filters, pick dinner) | `/generator` |
| Classics Wheel spin | `/wheel` or `/classics-wheel` |
| Explore / categories | `/explore` |
| Recipe page (crew scale, steps) | `/recipes/{slug}` e.g. smash-burgers, big-chili |
| Homepage hero + L&S branding | `/` |
| Breakfast (if needed) | `/breakfast` — **do not** imply it’s in dinner wheel |

**Hero slugs for food B-roll match:** smash-burgers, chicken-parm, pulled-pork, steak-tacos, big-chili, bbq-chicken-bowls, breakfast-burrito-bar (breakfast only).

## Content strategy — what wins

1. Relatable firefighter humor  
2. Kitchen-table culture  
3. Rookie jokes  
4. Post-call exhaustion  
5. “Big crew” meals  
6. Decision fatigue  
7. Realistic shift life  
8. Nostalgia / classics  
9. Anti-corporate authenticity  
10. Gritty realism  

## Avoid

- Polished influencer aesthetic  
- Fitness / “macro bowl” vibe  
- Fake cinematic acting  
- Generic food content with no station context  
- Overexplaining app features in VO  
- Calling breakfast part of the dinner wheel  

## Goal (viewer feeling)

> “Finally… someone built this for us.”

---

## Production checklist (per reel)

- [ ] Hook readable in &lt;1s (big type, high contrast)  
- [ ] Subtitles burned in (white text, black stroke)  
- [ ] At least one **authentic** station audio bed  
- [ ] No stock “smiling chef” energy  
- [ ] End card: **FirehallMeals.com** + **Built by Lights & Sirens Co.**  
- [ ] Export 1080×1920, H.264, &lt;15s  
- [ ] Cover frame: hook text + red/black grade

## Batch shoot order (efficient day)

1. Table / crew banter (Reels 2, 5, 7, 10)

4. Screen records at station (Reels 1, 8) — `/`, `/generator`, `/wheel`, `/explore`  
5. Post-call silent eat (Reel 7) — only if crew is willing
