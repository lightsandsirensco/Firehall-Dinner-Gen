# Push Code to GitHub

## What & Why
Connect this Replit project to the GitHub repository at https://github.com/lightsandsirensco/Firehall-Dinner-Gen.git and push all current code.

## Done looks like
- A `origin` remote pointing to `https://github.com/lightsandsirensco/Firehall-Dinner-Gen.git` is configured
- All current code is pushed to the `main` branch on GitHub
- `git push -u origin main` completes successfully

## Out of scope
- Automatic syncing on future saves (separate task)
- CI/CD setup

## Steps
1. Add the GitHub remote as `origin` with the URL https://github.com/lightsandsirensco/Firehall-Dinner-Gen.git
2. Ensure the current branch is named `main`
3. Push all commits to `origin main` with upstream tracking set

## Relevant files
- `.git/config`
