Redesign the Explore page recipe cards so they feel more like a premium food discovery app.

Goal:
Make the cards visually enticing and easy to browse so users want to keep scrolling recipes.

Do not change the app theme or break functionality.

Requirements:

1) Make the food image the hero element
- Image should take up the top portion of the card
- Maintain consistent aspect ratio across all cards
- Ensure the image is crisp and fills the card width
- Avoid awkward cropping or stretching

2) Improve the card layout hierarchy

Structure:

[Large Food Photo]

Recipe Title

Small tags / badges
Example:
🔥 High Protein
⏱ 30 Minutes
🌎 Mediterranean

Metadata row
Example:
Chicken • 6 Servings • 30 min

Action buttons
View Recipe

Spacing must feel balanced and clean.

3) Improve recipe title styling
- Slightly larger font
- Stronger weight
- Allow 1–2 lines maximum
- Avoid text wrapping awkwardly

4) Add subtle card polish
- soft shadows
- consistent rounded corners
- clean padding
- hover/tap elevation effect

The card should feel touchable and modern.

5) Improve hover / tap interaction
On hover (desktop):
- card lifts slightly
- subtle shadow increase
- image slightly zooms (very subtle)

On tap (mobile):
- clean transition to recipe page

6) Add visual tags
Each recipe card should include helpful badges such as:

🔥 High Protein  
⏱ 30 Minute Meal  
🍲 One-Pot  
🌎 Mediterranean  
🥗 Healthy  
🍔 Comfort Food  

Keep badges subtle and readable.

7) Improve card grid layout
Ensure Explore grid:

- consistent spacing
- balanced column layout
- no uneven card heights
- responsive for mobile and desktop

Example layout:

Desktop
3–4 columns

Tablet
2–3 columns

Mobile
1 column

8) Improve card loading state
Add skeleton loaders for images and titles so loading feels polished.

9) Keep performance fast
- lazy load images
- optimize image size
- do not significantly slow page load

Final goal:
Make the Explore page feel like a premium food discovery experience similar to a high-quality recipe or cooking app, encouraging users to keep scrolling and exploring meals.
