STEP 2 — Create Safe Analytics Helper
----------------------------------------

Add a reusable helper function in a global utilities file or near app initialization:

function trackEvent(name, params = {}) {
  if (typeof window !== 'undefined' && typeof window.gtag === 'function') {
    window.gtag('event', name, params);
  }
}

This prevents runtime errors if analytics fails to load.
